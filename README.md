# Kasane

Kasaneは、会議を録音して文字起こしし、議事録とチャットを提供するmacOSアプリです。このリポジトリは、配布用のファイルを置く場所です。ソースコードは含みません。

- ダウンロード: [Releases](https://github.com/hexis-ltd/kasane-releases/releases/latest)
- 紹介とインストールの手順: <https://www.hexis.ltd/kasane>

## 対応環境

- macOS 14以降
- Appleシリコン搭載のMac

Kasaneは招待制です。利用には、招待されたGoogleアカウントでのログインが必要です。

---

Kasane is a macOS app that records meetings, transcribes them, and provides minutes and chat. This repository hosts release downloads only; it contains no source code.

- Download: [Releases](https://github.com/hexis-ltd/kasane-releases/releases/latest)
- About and installation: <https://www.hexis.ltd/kasane>

Requires macOS 14 or later on Apple silicon. Kasane is invite-only.
